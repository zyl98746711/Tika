This is a sample HTML document for testing the RAG document parsing service. It contains structured content with headings and paragraphs.

Overview

The service uses Apache Tika to extract text and metadata from various document formats. It supports PDF, DOCX, PPTX, XLSX, HTML, Markdown, and many other formats.

Features

  • Multi-format document parsing
  • Metadata extraction
  • Multiple chunking strategies
  • REST API interface

Technical Details

Built with Spring Boot 3 and JDK 21, the service provides a high-performance document processing pipeline optimized for RAG applications.

Parsing Pipeline

The parsing pipeline consists of file type detection, content extraction, metadata extraction, and text normalization. Each step is designed to handle edge cases and provide robust error handling.

Chunking Strategies

Three chunking strategies are available: fixed-size, token-based, and hierarchical. Each strategy produces chunks with different characteristics suited to different use cases.
